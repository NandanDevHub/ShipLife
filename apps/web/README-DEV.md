# ShipLife Web (Next.js)

## Dev
- Env: `NEXT_PUBLIC_API_BASE_URL` (default `http://localhost:5080`)
- Run: `npm install && npm run dev`

## Pages
- `/` — dashboard + Daily Check
- `/ (board) / board` — Kanban, Card Drawer, Planner, Retro
- `/ (tools) / analytics` — summary
- `/ (tools) / search` — find cards
- `/ (tools) / export` — backup JSON
